# cookify
cookify is an AI-powered cooking assistant that helps users learn recipes interactively.

## Features
AI Cooking Tutor,
Save Favorite Recipes,
Browse hundreds of recipes,
Premium Membership,
Google sign-in,
Apple sign-in (pending),
Guest Mode,
Supabase Backend.

## Built with
React,
Vite, 
Supabase, 
Flutterwave, 
Google Gemini AI
